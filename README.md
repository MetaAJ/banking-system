# Banking System API

A backend banking application built with **Java, Spring Boot, Spring Data JPA, and H2**.

This project is being developed as a hands-on learning project while transitioning from Python development to Java/Spring Boot.

The goal is to build a realistic banking backend incrementally while learning Java, Spring Boot, JPA, database design, API design, transactions, concurrency, and eventually production-level concerns.

---

## Tech Stack

- Java
- Spring Boot
- Spring Web
- Spring Data JPA
- Hibernate
- H2 Database
- Maven
- Jakarta Bean Validation
- Postman for API testing
